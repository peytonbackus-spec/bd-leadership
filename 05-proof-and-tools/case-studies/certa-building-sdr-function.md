# Case Study: Building the Enterprise SDR Function (Certa)

## Executive Summary
Led the outbound SDR function at Certa (April 2025 – August 2026), establishing core GTM infrastructure, data enrichment pipelines, and AI-assisted research workflows for enterprise procurement and compliance solutions.

## Key Outcomes
- **Infrastructure & Stack Buildout:** Operationalized multi-channel outbound stack (Salesforce, Outreach, Orum, ZoomInfo, Clay) and established data governance standards.
- **AI-Assisted Workflows:** Engineered prompt frameworks and automation pipelines (`pipeline.py`) to streamline pre-call research and personalized opening lines.
- **Global Compliance Guardrails:** Implemented regional routing and consent controls across North American and international outbound motions (GDPR, CASL, CAN-SPAM).

## Core Capabilities Delivered
- Programmatic account scoring scripts (`score_accounts.py`).
- Automated LLM brief and hook generation pipeline (`pipeline.py`).
- Capacity planning models for headcount and activity forecasting.
