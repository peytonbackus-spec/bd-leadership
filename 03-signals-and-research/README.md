# 03. Signal Library & Research Standards

## Signal Hierarchy & Action Triggers
1. **Executive Leadership Change (VP+ Finance / Operations / RevOps):**
   - *Window:* First 90 days of tenure.
   - *Action:* Send "First 90 Days Modernization" campaign.
2. **Job Postings / Hiring Expansion:**
   - *Window:* Active listing within 14 days.
   - *Action:* Cite expansion role in opening line of cold call & email.
3. **Tech Stack Switch / Integration Addition:**
   - *Window:* Identified via BuiltWith / HG Insights.
   - *Action:* Deploy competitive displacement framework.
