# Tailoring AI Output to Each Rep

> **Done** items ran at a B2B SaaS company with account managers, customer success managers and install owners, about 21 users in all (est.), not with a BDR team. All figures are my own estimates (est.). **Would do** items are how I would apply the same practices to BDR-facing output. Nothing here is a measured result.

## What I did (Done)

AI agents wrote drafts that went to reps. Three practices made the drafts usable:

| Practice | What it looked like |
|---|---|
| **Tailor to the rep** | Output matched each rep's communication style, so the same facts read differently for different reps |
| **Fix the shape from real use** | Reworks came from reps' feedback, such as a Slack character limit and how often messages were sent |
| **Check before it reaches anyone** | Human-written reference outputs set the language and tone; a test set was re-run after every prompt change; a person reviewed each output before delivery; errors and decisions were logged |

## How I would apply it to a BDR team (Would do)

- **A one-line style profile per BDR** (length, tone, how much detail), kept with the 1:1 notes and updated when the BDR corrects a draft.
- **Channel limits as hard rules** for any draft, such as message length and how many touches go out per day, written down before the draft is generated.
- **Reference examples written by the team's best callers and writers,** used to judge drafts for language and tone.
- **Re-check the sample set whenever a prompt changes,** and review a sample of drafts in the weekly 1:1 (see the [coaching framework](./README.md)).
- **A person sends.** The BDR reviews and sends every draft; see [Hybrid Team Ownership & Quality-Gated Comp](./hybrid-team-ownership-and-comp.md).
