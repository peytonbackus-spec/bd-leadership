# SYSTEM GOVERNANCE & BEHAVIORAL MANUAL

## 1. What This Repo Is
Curated BDR/SDR-leadership subset of `gtm-revops-toolkit`, built specifically for Peyton's Loopio Manager, Business Development application -- coaching frameworks, ICP/account-scoring, outbound cadence/messaging, and GTM-tool evaluation content, with consulting/client content removed.

## 2. Operating Rules & Boundaries
- **Public repo:** never add confidential business content, client-specific data, or real company data.
- **Scope discipline:** this repo is intentionally narrower than `gtm-revops-toolkit` -- resist pulling the full toolkit's consulting/RevOps-engineering content back in unless explicitly asked. If something looks like a gap, say so rather than silently importing it.
- **Publishing:** never `git commit`/`git push` to the remote unless explicitly asked in that message. Local edits are fine; publishing them is not the default.

## 3. Note Schema
Follow whatever frontmatter/structure convention the existing files in this repo already use -- check a couple of real files before adding a new one, don't assume the private vault's schema (confidence_score, wikilinks) applies here without checking first.

## 4. Execution Environment
- Primary OS: macOS (Zsh)
- Primary Stack: Claude Code + Model Context Protocol (MCP)
