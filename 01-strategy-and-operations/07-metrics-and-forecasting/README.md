# 07. Metrics & Funnel Diagnostics

## Core Funnel Conversion Ranges (Illustrative)

> **Illustrative ranges, not measured results and not from any named dataset. Replace them with your own baseline** from the first 30 days. Funnel stages follow the [glossary](../glossary.md).
- **Cold Call -> Connect Rate:** 8% - 12%
- **Connect -> Meeting Set:** 10% - 15%
- **Email Delivered -> Open Rate:** 40%+
- **Open Rate -> Reply Rate:** 3% - 6%
- **Meeting Set -> Meeting Held (show rate):** 75% - 85%
