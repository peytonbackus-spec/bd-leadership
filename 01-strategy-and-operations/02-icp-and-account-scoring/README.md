# 02. ICP & Account Scoring Framework

This module contains the specification and execution scripts for evaluating, scoring, and tiering target accounts based on Firmographic Fit and Real-Time Intent Signals.

## Scoring Methodology
- **Tier 1 (Score >= 80):** High Fit + Active Signal. Direct custom outreach, AI research brief, high-touch cadence.
- **Tier 2 (Score 50-79):** Moderate Fit + Indirect Signal. Semi-automated sequence, high phone volume.
- **Tier 3 (Score < 50):** Low Fit / Unqualified. Nurture sequence or excluded.
